# 日本妖怪文化研究语料库

一部长篇小说所需的日本妖怪文化背景调查。**自足仓库**——结论与证据同处一地，
不依赖任何外部站点继续在线。

## 置信度标记

- `【A】` 原始页面可查（快照存于 `archive/`）
- `【B】` 单一可靠来源，未回溯原页
- `【存】` 未能核实，**正文不得引用**

`【快照 pages/xxx.html】` 指向本地证据；`【无快照｜…】` 说明该来源已下线或本机不可达。

## 关于网址

**正文不载任何网址。** 原始 URL 只保留在 `archive/pages/index.json`
（原 URL → 本地文件、HTTP 状态、SHA-256、抓取时间），机器可读，供溯源。

## 复现

```bash
python3 scripts/grab_archive.py    # 抓卡片页 + 图像 + IIIF manifest
python3 scripts/grab_pages.py      # 抓本库引用的外部页面
python3 scripts/fetch_authors.py   # 逐件补齐「著作者」等字段
```

脚本均支持断点续跑：已存在的文件会跳过。

## 校验

正文自检（交叉引用有效性、残留日志体措辞、旧式编号、标题层级、标点残留）：

```bash
python3 scripts/check_yokai.py
```

图像完整性：181 张 JPEG 头尾魔数校验，**零损坏**。

## 数据来源

主源为日本国立国语研究所（国際日本文化研究センター）的
「怪異・妖怪伝承データベース」与「怪異・妖怪画像データベース」，
以及各自治体・文教机构的公开页面。完整出处见各文件末尾的「出处」节。
